# Neo Contract RS Website

This is the landing page for the Neo Contract RS project, a Rust framework and compiler for Neo N3 smart contract development.

## Deployment

This website is designed to be deployed on Netlify. Follow these steps to deploy it:

1. Create a new site on Netlify
2. Connect your GitHub repository
3. Set the following deployment settings:
   - Base directory: `website`
   - Build command: (leave empty)
   - Publish directory: `.`

## Local Development

To run this website locally:

1. Install a local server like `http-server`:
   ```
   npm install -g http-server
   ```

2. Navigate to the website directory:
   ```
   cd website
   ```

3. Start the server:
   ```
   http-server
   ```

4. Open your browser and navigate to `http://localhost:8080`

## Customization

Feel free to customize this website by:

## Website Structure

The website consists of the following sections:

1. **Hero Section**: Introduction to Neo Contract RS with a code example
2. **Features Section**: Highlights the key features of the framework
3. **Documentation Section**: Links to important documentation resources
4. **Examples Section**: Code examples showcasing the framework
5. **Getting Started Section**: Step-by-step guide to get started
6. **Call to Action Section**: Encourages users to get involved
7. **Footer**: Additional links and information
