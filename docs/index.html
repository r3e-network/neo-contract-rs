Neo Contract Rust

A framework for writing Neo N3 smart contracts in Rust using an ink!-inspired syntax

Overview

Neo Contract Rust is a comprehensive framework that enables developers to write smart contracts for the Neo N3 blockchain using Rust programming language. The framework provides a declarative attribute-based syntax inspired by Substrate's ink!, leveraging Rust's strong type system and memory safety while targeting the Neo N3 blockchain.

Architecture

The Neo Contract Rust framework consists of several components that work together to provide a seamless experience for writing Neo N3 smart contracts in Rust:

  • neo-contract: Core library for contract development with high-level abstractions
  • neo-contract-proc-macros: Procedural macros for processing attributes
  • neo-compiler: Tool to convert WebAssembly to Neo VM bytecode
  • neo-contract-testing: Testing framework for Neo contracts

The workflow is:

  1. Write Neo contracts in Rust using the framework's abstractions
  2. Compile to WebAssembly (WASM)
  3. Use neo-compiler to convert WASM to Neo N3 bytecode (.nef)
  4. Deploy to Neo N3 blockchain
